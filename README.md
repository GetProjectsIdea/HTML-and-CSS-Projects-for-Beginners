## 🛠️ How to Run Locally

Every project is self-contained with pure HTML, CSS, and lightweight vanilla JavaScript. No Node.js, npm, or build dependencies are required!

```bash
git clone https://github.com/GetProjectsIdea/HTML-and-CSS-Projects-for-Beginners.git
cd HTML-and-CSS-Projects-for-Beginners
# Open any folder (e.g. cd 02-neumorphic-calculator) and double-click index.html
```
